> 发起人：C（Isaac Sim/执行，吴昌庆）

>
> 优先级：P0，立即修改

## 1. 必须完成的字段迁移

B 输出的 `strategy.v1` 只允许以下第一阶段动作和参数：

| action | arguments | 说明 |
|---|---|---|
| `detect_object` | `{"object_id": "<稳定ID>"}` | 直接使用 A/任务中的稳定 ID，不再按名称搜索 |
| `move_to_object` | `{"object_id": "$<detect-step>.object_id"}` | 引用检测步骤的返回值 |
| `grasp` | `{"object_id": "$<detect-step>.object_id"}` | 引用检测步骤的返回值 |
| `move_to_target` | `{"destination_id": "<稳定ID>"}` | 使用目的地对象的稳定 ID |
| `release` | `{}` | 参数必须为空 |

旧字段 `object_name` 和 `target` 自本版本起停止使用。C 已经拒绝这两个字段，不再提供兼容分支。

```json
    }

  "mode": "primitive_plan"

```

## 3. B 必须执行的本地校验

- 只把 `status=READY`、`action=pick_and_place` 的任务交给 C。
- `target_ids` 必须恰好包含一个非空稳定 ID；`destination_id` 必须为非空稳定 ID。
- 所有 `step_id` 唯一；引用只能指向更早的步骤。
- 不生成动作白名单以外的动作，不输出脚本或任意 Python。
- `code` 必须为 `null` 或空字符串。C 会拒绝任何非空 `code`。
- CodeArts 返回非法 JSON、未知动作、错误实体 ID、超时或认证失败时，必须返回结构化阻断结果，不能提交给 C 猜测执行。

## 4. CodeArts 正式验收要求

日常开发可使用本地确定性策略；正式验收必须设置 `CODEARTS_STRATEGY_MODE=required`，禁止静默回退。每次真实调用至少记录：

- provider、模型和 Agent；
- request/session ID；
- 调用耗时、尝试次数和最终状态；
- 是否发生回退及原因；
- schema、实体 ID、动作白名单和安全校验结果。

B 需要保存至少三条真实成功记录，以及超时、非法 JSON、未知动作/错误实体 ID 中至少三类失败处理记录。密钥、密码和 Token 不得写入仓库或证据文件。
