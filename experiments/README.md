# 系统统一实验资料库

这个文件夹用于存放后续 A/B/C/D 整个系统的实验资料，方便查找、复现和整理 PPT。

## 文件夹怎么用

```text
experiments/
├─ protocols/    # 实验协议、实验规则、指标定义
├─ manifests/    # 本次实验实际使用的测试清单和案例版本
├─ runs/         # 每次运行产生的原始报告、日志和逐条记录
├─ summaries/    # 汇总后的指标表、对比结果、CSV/JSON
└─ ppt_assets/   # PPT 使用的图表、截图、典型案例和演示证据
```

## 归档规则

每次正式实验都建立一个独立的运行目录，例如：

```text
runs/20260828_exp_v0_rule_baseline/
```

目录中至少保存：

```text
metadata.json       # Git SHA、实验协议版本、机器、模型和运行参数
report.json         # 完整机器报告
stdout.log          # 标准输出
stderr.log          # 错误输出
records/             # 逐案例结果和可回放证据
```

## 命名建议

```text
日期_实验名称_方案名称_重复次数
20260828_core_v0_rule_r5
20260828_core_v4_full_r5
20260828_core_v2_no_d_r5
20260828_codearts_online_r3
```

## 使用原则

1. 测试清单一旦开始运行，不要中途修改；修改后必须增加新版本号。
2. 原始运行结果放进 `runs/`，不要只保留最终汇总表。
3. 汇总数据放进 `summaries/`，并注明来源运行目录。
4. PPT 中使用的图片和数字放进 `ppt_assets/`，同时保留对应的案例 ID。
5. 不要保存 API Key、AK/SK、密码或未经脱敏的服务器信息。
6. 统一实验协议见：`docs/统一实验协议_v1.md`。
