# 📊 动态运行状态与错误日志库（"黑匣子"）

> **无需人工上传！** 此目录中的文件由系统运行时自动生成。

---

## 自动生成的文件

| 文件 | 生成者 | 说明 |
|------|--------|------|
| `scene_state.json` | `src/isaac/get_scene_json.py` | 实时战场实体坐标和尺寸数据，每次场景变化时自动刷新 |
| `error_report_*.json` | `src/monitor/trace_probe.py` | **【闭环关键】** 机械臂异常时由探针自动生成的现场错误报告 |

---

## 闭环运作机制

```
仿真执行 → 探针捕获异常 → 生成 error_report.json
    → 发回 CodeArts → 触发 Reflexion 反思重写策略
    → 重新下发执行 → 再次监控 → ...
```

## 注意

- 此目录中的 JSON 文件不应手动编辑
- 异常报告保留最近 10 条，自动轮转清理
- `.gitkeep` 确保空目录可被 Git 跟踪
